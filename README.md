# İdeal Mebel: сайт

Одностраничный сайт для İdeal Mebel (мебель на заказ). Работает без сервера и без сборки: только HTML, CSS и JS.

## Что есть на сайте
- AZ / RU переключение языка
- Главный экран, преимущества, 6 категорий мебели
- Портфолио «Bizim işlər» с фильтром и просмотром фото на весь экран
- **Калькулятор цены**: тип мебели → длина или комплект → материал фасада → цвет → доп. опции. Эскиз мебели перекрашивается в выбранный цвет, расчёт одной кнопкой уходит в WhatsApp
- Как мы работаем (5 шагов), FAQ, форма заявки (открывает WhatsApp с готовым текстом)
- Плавающая кнопка WhatsApp, номер +994 55 207 15 03, Instagram @ideal__mebel_

## Как запустить на своём компьютере (localhost)

Нужен только Python (он у тебя уже есть).

**Windows:** дважды кликнуть `start.bat`.

**Или вручную:**
```bash
cd ideal-mebel
python -m http.server 8000
```
Открыть в браузере: http://localhost:8000

## Фото (важно сделать один раз)
```bash
python tools/download_photos.py
```
Скрипт скачает примерные фото с Unsplash в `assets/img/photos/`. После этого сайт открывается быстро, работает без интернета и готов для GitHub Pages.
Если не запустить скрипт, сайт берёт фото напрямую с Unsplash. Это медленнее и нужен интернет.

### Как поставить настоящие фото магазина
Положи фото в `assets/img/photos/` **с тем же именем**, например `kitchen1.jpg` или `wardrobe1.jpg`. Сайт сам возьмёт их вместо Unsplash.
Список имён находится в `assets/js/data.js` → `PHOTOS`. Подписи к работам там же → `WORKS`.
Логотип: положи `assets/img/logo.png`, и он заменит текстовый логотип.

## Что поменять перед показом клиенту
Всё в одном файле, `assets/js/data.js`:
- `CALC`: **цены в калькуляторе примерные**, их нужно согласовать с владельцем
- `CATEGORIES`: цены «от … ₼» на карточках категорий
- `SITE`: адрес, часы работы, число подписчиков

## Публикация на GitHub Pages
1. Создать репозиторий на github.com, например `ideal-mebel`
2. Загрузить все файлы этой папки (вместе с `assets/img/photos/`, если запускал скрипт)
3. Settings → Pages → Source: *Deploy from a branch* → `main` / `root` → Save
4. Через 1–2 минуты сайт будет по адресу `https://<твой-логин>.github.io/ideal-mebel/`

Фото Unsplash распространяются по [Unsplash License](https://unsplash.com/license): бесплатно, в том числе для коммерческого использования.
